# ITW PPF 小程序改进建议（产品视角）

初稿：2026-10-03；状态更新：2026-11-02。以下仅为未实施的改进建议，不属于本期已确认范围；需单独确认后再开发。当前功能以产品开发文档和本期需求清单为准。

## P0 影响核心转化，建议上线前做

1. **游客能看产品，资料再设门槛**（两库已确认局部预览＋居中注册卡片；开放完整游客列表仍需另行确认）
   现状：产品库列表显示局部预览及居中注册卡片，完整列表交互和详情仍要求注册（products.js 调用 lockFor('registered')），转发出去的产品卡片，对方没注册时打开就是遮罩。
   建议：产品列表、产品名、品牌介绍、规格对游客开放；技术资料、视频、价格和咨询入口再引导注册。新客户先看到价值再注册，转化更高。

2. **增加「我的申请」记录和进度**
   现状：需求咨询和经销商申请尚未接入真实提交，认证仍保留测试流程；会员中心尚无申请记录和处理状态页面。
   建议：会员中心加「我的咨询 / 我的申请」，显示 待处理 / 已联系 / 已完成；后台对应 CRM 跟进状态。

3. **用微信订阅消息通知结果**
   可考虑提供认证、咨询和经销商申请的结果通知，具体微信渠道、接收条件和模板需核实。它与本期提出的“给指定销售发送业务机会通知”是不同流程，两者均尚未实现。

4. **注册改用微信手机号一键授权**
   现状：手机号 + 短信验证码手填。建议首选 getPhoneNumber 一键获取，手填作为备选，可明显减少注册流失。

5. **需求咨询的产品选择改为搜索**
   现状：从产品详情进入会自动带上产品，但直接进入时是 528 项的下拉 picker，几乎没法选。建议改成可搜索选择，支持多选产品。

## P1 提升使用体验

6. **产品详情补技术资料下载**：TDS / SDS / 施工指南 PDF 是工业客户最常找的内容，建议每个产品挂资料位（认证级可下载）。
7. **产品详情加「相关应用」和「同系列产品」**，应用详情加「推荐产品」，形成应用 ↔ 产品互相跳转。
8. **搜索增强**：本期已完成六类内容搜索、页面正文与行业字段匹配、同义词和加载更多。仍可另行考虑搜索历史、产品代码精确命中置顶、联想词，以及后台热门词配置。
9. **在线客服 / 联系销售**：详情页加客服按钮（微信客服或企业微信），或按地区显示销售联系人。
10. **列表页支持转发和朋友圈分享**：目前只有详情页、首页、文章等 7 个页面有分享，产品库、应用库列表没有；分享卡片建议用产品图。
11. **最近浏览**：会员中心加「最近浏览」，方便销售和客户回头找。
