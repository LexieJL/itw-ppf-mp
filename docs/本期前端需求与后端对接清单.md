## 已确认的数据规则

- 个人关注、代理意向：`industrySelections: [{marketId, marketName, segmentId, segmentName}]`，允许跨市场多选。
- 单次咨询：`marketId, marketName, segmentId, segmentName`，一个完整有效配对。
- 咨询归属独立于个人关注，不自动把全部关注行业带入咨询。
- 经销商新增 `brandsProducts` 必填文本字段。
- 原生咨询载荷包含 `type: sample | visit | general`、`productId`、`applicationId`，不将下拉序号作为未来接口的主键。
- 表单分类在 `utils/markets.js` 中维护，共七个市场、41个细分行业，按 PPT 第8页录入。表单 ID 与旧应用目录 ID 分离，防止新增分类造成旧应用/资料关联错位。后台需要建立稳定映射，不能按数组下标对应。
- “新能源电池”“新能源动力电池”“新能源汽车动力电池”作为搜索同义词处理。

## 后续确认：正文咨询卡片改为更多视频资料（2026-11-02）

产品详情底部固定的需求咨询按钮保留。原正文咨询卡片的位置改成“更多视频资料”区域，支持多个视频及其标题和封面；未添加资料时显示“暂无更多视频资料”，不显示虚假播放按钮。原产品视频区域继续保留。

产品数据增加 `additionalVideos` 数组，单项格式与现有 `videos` 一致：`{ id, title, src, poster, access, visible }`。`src` 为真实可播放地址，`poster` 为可选封面。同一个视频地址在主视频和补充视频区之间去重，仍遵守资源权限与隐藏规则。现阶段可在产品前端数据中配置；后台后续提供上传、产品关联、排序和字段回传，不新增访客上传入口。

## 追加：游客应用预览（2026-11-02）
