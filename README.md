## 本期前端修改

本期仅修改中文前端，覆盖原生小程序和网页演示。英文版留到第二阶段，ACH 暂不调整。

| 模块 | 当前行为 |
|---|---|
| 首页 | Banner 支持手动滑动与自动轮播；模块可通过本地配置添加、隐藏、排序、更换背景及设置跳转 |
| 工业电商 | 改为乐语小程序入口；目标 AppID、路径待提供，未配置时提示暂未开放 |
| 应用库与详情 | 游客可浏览列表、图片及公开摘要；详情下方渐变引导注册/认证，完整方案、视频、文档仍按权限显示 |
| 产品库 | 删除顶部横向分类“全部”，默认选中首个有效系列，保留左侧品牌栏 |
| 产品详情 | 保留底部固定“需求咨询”；正文原咨询卡片改为“更多视频资料”，支持多条视频、标题、封面；无资料时显示空状态 |
| 会员注册 | 普通会员和认证会员可跨市场多选关注的细分行业，并查看、移除已选项 |
| 经销商申请 | 跨市场多选意向行业，独立填写必填的“品牌和产品” |
| 需求咨询 | 三类表单均新增必填的市场、细分市场联动单选；切换市场清空旧细分项，保留原“选择应用” |
| 全站搜索 | 产品、应用方案、推文、视频、文档、知识库六类；匹配名称、简介、已有正文及关联行业，支持同义词与加载更多 |

注册关注和代理意向允许多选，单次咨询只对应一个市场及细分行业，两者分别保存。表单分类共 **7 个市场、41 个细分行业**。

搜索针对当前已加载内容，不抓取外部推文全文，不读取 PDF/Word 附件内部正文。

## 后台与资料待办

- **真实提交与审核**：咨询、经销商申请目前只进行前端校验并准备载荷，尚未发送。注册仍保留测试开关。

- **乐语及正式素材**：补充目标小程序 AppID、路径、产品图片和视频等资料。

完整字段及对接约定见下方文档，以上待办不代表后台已经完成。

## 本地运行

1. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)「导入项目」，选择本仓库根目录。
2. AppID 暂用测试号 `touristappid`，正式开发时在 `project.config.json` 换成 ITW 的小程序 AppID。
3. 「会员中心」底部有测试用的身份切换，可查看不同权限下的界面。

## 目录结构

```
pages/          21 个页面（首页、应用库、产品库、会员中心、知识库、需求咨询等）
components/     公共组件：市场多选、权限遮罩、搜索收藏浮窗、行业导航、详情页底栏
utils/          市场字典、资源处理、搜索规则、首页配置、角色权限、收藏和数据
images/         ITW Logo、品牌 logo、首页模块图标
tools/          产品数据生成、网页共享配置同步脚本
tests/          表单、搜索、资源及页面渲染的离线回归检查
docs/           项目文档
preview.html    网页版原型（即在线原型的源文件）
```

每个页面对应的 PPT 页码和功能见[产品开发文档](docs/小程序产品开发文档.md)第 3、4 节。
