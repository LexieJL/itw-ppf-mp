# ITW PPF 小程序前端

ITW PPF 微信小程序的前端代码（原生 WXML / WXSS / JS）。本团队依据《小程序操作逻辑需求_逐页回复20260922.pptx》和《小程序项目ITW反馈.pptx》实现，目前使用测试数据，尚未接入后端。

## 👉 在线原型

**https://lexiejl.github.io/itw-ppf-mp/**

浏览器直接打开即可点击浏览，可切换游客 / 普通会员 / 认证会员 / ITW员工四种身份查看。

## 本地运行

1. 用[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)「导入项目」，选择本仓库根目录。
2. AppID 暂用测试号 `touristappid`，正式开发时在 `project.config.json` 换成 ITW 的小程序 AppID。
3. 「会员中心」底部有测试用的身份切换，可查看不同权限下的界面。

## 目录结构

```
pages/          21 个页面（首页、应用库、产品库、会员中心、知识库、需求咨询等）
components/     公共组件：权限遮罩、搜索收藏浮窗、行业导航、详情页底栏
utils/          角色权限、运营配置（cms.js）、统一跳转、收藏、测试数据、产品数据
images/         品牌 logo、首页模块图标
tools/          从 ITW 产品表重新生成产品数据的脚本
docs/           项目文档
preview.html    网页版原型（即在线原型的源文件）
```

每个页面对应的 PPT 页码和功能见[产品开发文档](docs/小程序产品开发文档.md)第 3、4 节。

## 权限

| 内容 | 游客 | 普通会员 | 认证会员 / 员工 |
|---|---|---|---|
| 首页、工业电商、搜索、活动专题 | ✓ | ✓ | ✓ |
| 应用库、产品库、收藏、需求咨询、成为经销商、常见问题库 | 提示注册 | ✓ | ✓ |
| 应用详情、公司介绍、产品培训 | 提示注册 | 提示认证 | ✓ |

## 上线前必须修改

- `pages/register/register.js`：`ALLOW_EMPTY` 和 `AUTO_CERTIFY` 改为 `false`（测试期允许空表单、认证自动通过）。
- 删除「会员中心」底部的测试身份切换。
- 本地测试数据换成 CloudBase 接口，详见[后端接口文档](docs/小程序后端接口文档.md)。
